# OpenNOW PS5 0.0.2-alpha

This prerelease adds persistent NVIDIA login to the native PS5 prototype. Public tag
`0.0.2-alpha` maps to native content version `00.002.027`, title ID `PPSA99082`.

## Changes

- Save the NVIDIA device identity and login credentials in `/data/opennow/account.bin`,
  outside the installed title folder, for restoration after app closure, console reboot
  and app replacement.
- Renew credentials automatically using NVIDIA client tokens, with OAuth refresh-token
  fallback when available. Preserve the cloud JWT when renewal omits `id_token`.
- Keep saved credentials on network outages, rate limits, unexpected HTTP errors and
  malformed renewal replies; retry automatically rather than forcing device authorization.
- Write an owner-only cache through a synchronized temporary file and atomic rename,
  using PS5 kernel file APIs. Save rotated credentials before further network requests.
- Show `ACCOUNT SAVED` or `ACCOUNT NOT SAVED`. Circle in the catalog signs out and
  removes the saved login; closing through the PS menu and stopping a game keep it.
- Renew between games so blocking authentication requests do not interrupt live media.
- Include the updated launcher artwork and repository contributor credits.

## Validation

Synthetic ASan/UBSan regressions passed for process restart, device-identity restoration,
renewal and rotation, omitted identity tokens, OAuth fallback, temporary failures,
corrupt caches, failed replacement, cache permissions and explicit sign-out. Existing
streaming, decoder-ownership, protocol and cloud-lifecycle regressions also passed.
The native GPU build and import audit passed on the remote Linux builder.

The native title was installed with a complete rollback copy, and all 31 activated
files were read back and SHA-256 verified in confirmed raw SELF transfer mode.
Installation integrity does not establish successful account restoration on the console.
A fresh sign-in, app relaunch, full console reboot and later app update remain live
acceptance checks for this feature.

The previous `00.002.026` console measurements remain historical evidence for the
unchanged video pipeline: approximately 92 pictures/s for a 4K Main10 SDR stream.
No new FPS or HDR result is claimed for this prerelease.

## Installation

Download `OpenNOW-PS5-0.0.2-alpha.zip`, its manifest and `SHA256SUMS`. Verify the
checksums, close OpenNOW completely and back up the current title before replacement.
Install the complete `PPSA99082` folder through a compatible native homebrew directory
loader. Keep `/data/opennow` when updating; it holds private account and launch-age data.
This is a directory package, not a retail PKG.

After installing this version, complete NVIDIA device authorization once and check
for `ACCOUNT SAVED`. Close through the PS menu to preserve the login. See the repository
README for private launch-age configuration, controls and loader requirements.

## Known limitations

The UI and catalog navigation remain basic. Real sustained 120 FPS, HDR game streams,
H.264 throughput parity and broader firmware/loader compatibility remain unverified.
Audio is stereo only. NVIDIA may require a new sign-in when renewal credentials expire
or are revoked. The local account cache contains sensitive credentials without encryption;
keep it private and never include `/data/opennow` in issue reports or release archives.

Source, pinned upstream revisions and build scripts are provided in the tagged repository
and accompanying source archive. No account data, private configuration, gameplay captures,
console dumps, proprietary SDK binaries or firmware modules are included.
