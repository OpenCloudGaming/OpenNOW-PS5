# OpenNOW PS5 0.0.5-alpha

This prerelease refines the search keyboard and streaming status labels.
Tag `0.0.5-alpha` maps to native content version `00.002.035`, title ID `PPSA99082`.

## Changes

- Remove the extra SPACE button. Keep one space key between `-` and `.`, marked
  with a space symbol; `_` still enters a literal underscore.
- Group digits in a separate numeric keypad: `123`, `456`, `789`, then `0`.
- Adapt directional navigation to the letter grid and numeric keypad.
- Reposition the video OUTPUT label so it fits within the screen margins.
- Show HDR or SDR explicitly on every streaming profile, including QUALITY.
  Profiles describe requested settings; OUTPUT describes the detected video output.

## Validation and limitations

The keyboard input and navigation regression passed with ASan/UBSan. Search and
output-layout previews were visually checked. The final GPU package was built
on the Linux VPS and its native import audit passed. All 32 installed files were
read back and SHA-256 verified, with the previous title tree retained for rollback.
The latest keyboard and label changes still require user acceptance on the console.
No new streaming performance, sustained 120 FPS or HDR playback results are claimed.

The earlier title-specific launcher background repair remains private and is not
included in this package. Existing installations may require their loader's
supported artwork refresh procedure. Reboot persistence of that private repair
has not been confirmed on the console.

## Installation

Download `OpenNOW-PS5-0.0.5-alpha.zip`, its manifest and `SHA256SUMS`. Verify
checksums, close OpenNOW and retain a rollback copy before replacing the complete
`PPSA99082` folder through a compatible native homebrew directory loader.
Preserve `/data/opennow`, which contains private login and launch-age data.
This is a directory package, not a retail PKG.

The source archive includes tracked sources, pinned upstream revisions and
licenses. Release assets exclude personal configuration, private console repair
tools, diagnostics, captures, dumps and proprietary SDK binaries.
