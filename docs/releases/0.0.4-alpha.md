# OpenNOW PS5 0.0.4-alpha

This prerelease improves controller hints and search input. Tag `0.0.4-alpha`
maps to native content version `00.002.032`, title ID `PPSA99082`.

## Changes

- Replace button names with antialiased outline icons of consistent size.
- Align icons and action labels in shared columns; remove duplicate hints.
- Use recognizable direction arrows, D-pad and Options symbols.
- Make `_` enter a literal underscore and give spaces a separate `SPACE` key.
- Remove the redundant `_ = SPACE` legend and support the extra keyboard row.

## Validation and limitations

Catalog and search previews were visually checked. The search-input and navigation
regression passed with ASan/UBSan. The GPU build and native import audit passed
on the Linux VPS. All 32 console files were SHA-256 verified, with a complete
rollback copy retained. The user confirmed the revised UI on the PS5.

The console's missing launcher background reference was repaired separately,
with persistent guards tested against reference resets and reinsertion on a
copy of the title database. Console read-back and user confirmation passed;
a full reboot remains unverified. That console-specific repair is not included
in this package. Existing installations may require their loader's supported
artwork refresh procedure. No new streaming performance or HDR results are claimed.

## Installation

Download `OpenNOW-PS5-0.0.4-alpha.zip`, its manifest and `SHA256SUMS`. Verify
checksums, close OpenNOW and retain a rollback copy before replacing the complete
`PPSA99082` folder through a compatible native homebrew directory loader.
Preserve `/data/opennow`, which contains private login and launch-age data.
This is a directory package, not a retail PKG.

The source archive contains tracked sources, pinned upstream revisions and
licenses. Release assets exclude personal configuration, console diagnostics,
private repair tools and proprietary SDK binaries.
