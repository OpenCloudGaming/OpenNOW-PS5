# OpenNOW PS5 0.0.3-alpha

This prerelease adds controller-driven catalog search, clearer controls and ALPHA
branding. Public tag `0.0.3-alpha` maps to native content version `00.002.030`,
title ID `PPSA99082`.

## Changes

- Fix Square returning HTTP 400: browsing no longer sends an empty search query.
- Open the full catalog at startup instead of filtering for Minecraft.
- Show the selected store entry and whether another catalog page is available.
- Triangle opens a controller-operated search keyboard. Options submits the search;
  R1 advances through results and Square returns to the full catalog.
- L1+R1 together signs out and removes the saved login. Circle in the menu closes
  the app while preserving login; Circle in the keyboard cancels text entry.
- Replace worker-thread `exit()` with coordinated worker/render shutdown and a
  system application-exit request on the main thread.
- Add visible `+` glyphs and `|` separators to the command labels.
- Add an ALPHA ribbon to the launcher, in-app and README logos. Include the
  selection and launch backgrounds.

## Validation and limitations

Synthetic ASan/UBSan authorization, persistence, catalog, search-input, pagination,
streaming and decoder regressions passed. Host previews were visually checked.
The GPU package was built and its native imports audited on the remote Linux host.
All 32 installed files were read back and SHA-256 verified with rollback copies.

The user confirmed the new home-screen logo after a reboot and the background
without another reboot after the existing title's missing background references
were repaired separately. This release does not modify the console's title database
or include that private repair tool. Existing installations may need the loader's
supported artwork refresh or re-registration procedure.

The revised Circle shutdown path still needs live console acceptance. The keyboard
and controls remain a basic prototype. No new streaming FPS or HDR measurements
are claimed; the previous approximately 92 FPS UHD Main10 SDR result is historical.
Broader firmware/loader compatibility, sustained 120 FPS and HDR game streaming
remain unverified.

## Installation

Download `OpenNOW-PS5-0.0.3-alpha.zip`, its manifest and `SHA256SUMS`. Verify the
checksums, close OpenNOW and retain a rollback copy before replacing the complete
`PPSA99082` folder through a compatible native homebrew directory loader.
Keep `/data/opennow` when updating; it holds private login and launch-age data.
This is a directory package, not a retail PKG.

The source archive includes pinned upstream revisions, build scripts and third-party
licenses. Release assets exclude account data, personal configuration, console logs,
dumps, gameplay captures and proprietary SDK binaries. NVIDIA can require a new
sign-in when renewal credentials expire or are revoked.
