# OpenNOW PS5 0.0.1-alpha

First public alpha of the native PS5 GeForce NOW client. This is a **functional, console-tested prototype**, with a rough interface primarily intended to validate authentication, video, audio and input. It is not a finished application.

The release packages development build **00.002.026**, title ID **PPSA99082**, without modifying its tested executable or title files.

## Included

- NVIDIA device authorization, game/store catalog and cloud session lifecycle.
- Native Videodec2 decoding, full-screen GPU presentation, stereo Opus audio and DualSense input.
- Qualified asynchronous UHD Main10 decoding with distinct retained input buffers, FIFO picture metadata, safe GPU surface leases and fallback on decoding failure.
- Fixed-quality native negotiation and selectable 4K120/90 HDR and SDR targets, plus 4K60 HDR and lower-resolution compatibility modes.

## Validation

Host ASan/UBSan regressions and the native build/import audit passed. All 29 installed title files were read back and SHA-256 verified. Console startup passed a 32-picture depth-three Main10 qualification across resets and full drain/resume cycles, with sampled luma/chroma equality, FIFO timestamps, GPU imports and a completed flip.

The latest live test received, decoded and drew approximately **92.4 pictures/s at 3840 × 2160 and 51 Mb/s**. Cumulative RTP/AU loss, queue drops, decoder resets and API errors remained zero after **19 minutes 30 seconds**. The tester reported fluid motion. Application draw counts precede buffer swap and do not independently measure physical screen cadence or end-to-end latency.

## Known limitations

- The tested stream was **10-bit BT.709 SDR**, despite requesting HDR. Sustained real 120 FPS and HDR game streaming remain unverified.
- Requested 90 FPS profiles previously received 60 FPS. Server behavior and game rendering can differ from the selected target.
- H.264 SDR profiles currently use depth-one decoding and do not inherit the Main10 pipeline's measured throughput improvement.
- The interface is unfinished and intended mainly for functionality testing; catalog navigation is basic.
- Account persistence, refresh and broad firmware/loader compatibility are not implemented or validated. Audio is stereo only.

## Download and installation

Download `OpenNOW-PS5-0.0.1-alpha.zip`, `OpenNOW-PS5-0.0.1-alpha.manifest.json` and `SHA256SUMS`. The ZIP contains the `PPSA99082` title folder, installation instructions and license notices. Verify checksums before installation. See the repository README for the required homebrew loader environment and private launch-age configuration.

Public tag `0.0.1-alpha` maps to native content version `00.002.026`. Source, pinned upstream revisions, public dependency build scripts and local runtime modifications are provided by the tagged repository. No account data, private configuration, gameplay captures, console dumps, proprietary SDK or firmware modules are included.
